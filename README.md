## 📝 Sobre o Repositório

Este espaço serve como um portfólio de evolução técnica. Aqui, aplico os conceitos teóricos do framework na prática, construindo desde rotas simples até sistemas complexos com autenticação, banco de dados e APIs.

---

## 📂 Grade de Estudos (Módulos)

Acompanhe o que já foi implementado e estudado até agora:

| Módulo | Descrição Técnica | Status |
| :--- | :--- | :---: |
| **01. Fundamentos** | Instalação, Estrutura de Pastas e Rotas (`web.php`). | ✅ |
| **02. Views & Blade** | Herança de templates, diretivas e componentes. | ✅ |
| **03. Banco de Dados** | Migrations, Seeders e Eloquent ORM. | ✅ |
| **04. Controllers** | Lógica de negócio e validação de Requests. | ✅ |
| **05. Autenticação** | Uso de Laravel Breeze / Fortify para Login e Registro. | 🔄 |
| **06. APIs & Resources** | Criação de endpoints JSON e tratamento de dados. | ⏳ |

---

## 🛠️ Tecnologias e Ferramentas

- **Framework:** Laravel 10/11
- **Linguagem:** PHP 8.x
- **Banco de Dados:** MySQL / PostgreSQL
- **Frontend:** Blade, Tailwind CSS / Bootstrap
- **Ferramentas:** Composer, Artisan CLI, Mailtrap (testes de e-mail).
